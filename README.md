# Afi Studio

Source code website **Afi Studio** — platform komunitas untuk berbagi aset Minecraft buatan sendiri: model 3D, rig, map, dan furniture, yang bisa didownload dan dipakai bareng-bareng oleh sesama animator/builder Minecraft.

Selain galeri aset, ada juga halaman tutorial, ranking kontributor, profil member komunitas, dan event — semuanya dikelola lewat admin panel sendiri.

🔗 **Live:** [afi-studio.vercel.app](https://afi-studio.vercel.app)

Dokumentasi teknis lengkap (arsitektur, API, cara jalanin lokal) ada di **`PANDUAN-PROYEK.md`**.
